### 方案四：性能优化 ⭐⭐

```swift
// 1. 提升刷新率
displayLink?.preferredFramesPerSecond = 60

// 2. 帧率独立动画
private var lastUpdateTime: TimeInterval = 0

@objc private func updateAnimation() {
    let currentTime = CACurrentMediaTime()
    let deltaTime = currentTime - lastUpdateTime

    // 限制最大delta，避免标签切换时动画爆发
    let cappedDelta = min(deltaTime, 0.1)
    lastUpdateTime = currentTime

    // 基于时间的动画计算
    simulationTime += cappedDelta
}

// 3. 改进 dB 转换公式
private func normalizePower(_ power: Float) -> Float {
    // GYSpectrum 方法（更精确）
    return max(0.0, min(1.0, 1 - pow(10, power / 20)))
}
```

## 技术债务与风险

### 已知风险
1. **Canvas渲染**: 复杂度高，可能影响现有布局逻辑
2. **手势冲突**: 需要与现有点击录音模式兼容
3. **性能影响**: 60 FPS 可能增加 CPU 占用

### 建议
- 采用渐进式增强，非大规模重构
- 保留现有接口，确保向后兼容
- 分阶段实施，P0 优先

**核心原则**: 集合 25+ 库的优势，重点借鉴 GYSpectrum（视觉效果）+ iRecordView（交互设计）+ DSWaveformImage（渲染优化）

**保留不变**:
- ✅ 现有对称布局作为默认

**新增价值**:
- ✅ QQ经典风格（渐变+视觉效果）
- ✅ 完整手势交互（长按+滑动取消）
- ✅ 60 FPS 流畅动画
